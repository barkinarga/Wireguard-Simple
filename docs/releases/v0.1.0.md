WireGuard Simple v0.1.0 is the first development release, with an independent Go server and embedded Turkish interface.

- Client management, QR codes, configuration downloads, live traffic, and administrative events.
- Optional history with retention and disk limits, disabled by default.
- Administrator authentication and optional read-only Prometheus access.
- A self-contained installer selecting amd64 or arm64 for Debian and Ubuntu.

See the current [installation guide](https://github.com/barkinarga/Wireguard-Simple/blob/readme/INSTALL.md) for the latest version.

The installer installs the panel and required tools. Existing VPN interfaces, NAT, forwarding, DNS, and firewall rules remain under administrator control. Internet routing requires separate network configuration. Real Linux VPN connectivity and production conditions were not validated for this development release.
